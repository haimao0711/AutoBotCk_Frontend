📌 SAU KHI PUSH CODE LÊN SERVER, CHỈ CẦN CHẠY:

    chmod +x deploy.sh && ./deploy.sh

✅ Script sẽ tự động:
   • Build Docker image mới
   • Deploy container mới
   • Tự động setup/gia hạn SSL (không cần làm gì!)
   • Khởi động nginx và certbot
   • Hiển thị trạng thái

═══════════════════════════════════════════════════════════════════

📋 SETUP LẦN ĐẦU (chỉ cần làm 1 lần):

1. Cấp quyền cho scripts:
   chmod +x deploy.sh setup-ssl-auto.sh

2. Tạo file .env.production (nếu chưa có)

3. (Tùy chọn) Chỉnh email trong setup-ssl-auto.sh (dòng 6)
   Thay: EMAIL="admin@${DOMAIN}"
   Thành: EMAIL="your-email@domain.com"

4. Chạy deploy:
   ./deploy.sh
